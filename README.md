# CabShare

Biblioteca gratuita de impulse responses para guitarra, baixo, violão, plugins, DAWs e pedaleiras.

https://cabshare-irs.netlify.app/

## O que tem no catálogo

- 1000+ IRs catalogados
- Filtros por instrumento, marca, amp, acesso e sample rate
- Separação entre download direto e fonte oficial
- Colecoes de Fender, Mesa Boogie, Marshall, Ampeg, Aguilar, Eden, Trace Elliot, Markbass, Hartke, Gallien-Krueger e outras marcas
- Interface pública, sem login

## Texto rapido para divulgar

Lancei o CabShare: uma biblioteca gratuita com mais de 1000 IRs para guitarra, baixo e violão. Dá para filtrar por marca, amp, gabinete, microfone, sample rate e ver o que tem download direto.

## Compartilhe

Se você toca guitarra, baixo, grava em casa, usa plugin, DAW, Helix, HeadRush, Mooer, Ampero, Quad Cortex ou outro modelador, o CabShare pode economizar muito tempo procurando IR em ZIP gigante.
